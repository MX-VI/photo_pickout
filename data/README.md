# Photo Pickout 数据准备指南

## 支持的两种标注方式

### 方式一：简单分类（适合快速开始）

只需要将照片放入 `good/` 或 `bad/` 文件夹即可开始训练。

**优点**：
- 无需额外标注工作
- 快速上手
- 适合初步实验

**缺点**：
- 无法学习三个维度的独立特征
- 模型只能输出近似的平均分

### 方式二：多维度精细标注（推荐）

为每张照片标注构图、表情、动作三个维度的分数，模型可以学习更精细的评判标准。

**优点**：
- 模型能独立评判每个维度
- 可以发现照片的具体优缺点
- 评分更专业、更有参考价值

**缺点**：
- 需要额外时间进行标注
- 标注质量直接影响模型效果

## 多维度标注方法

### 1. 使用标注工具

```bash
# 命令行快速标注（推荐）
python src/annotate.py ./data/good --output ./data/annotations.json

# 图形界面标注（需要桌面环境）
python src/annotate.py ./data/good --gui
```

### 2. 标注界面说明

**命令行模式**：
```
[1/100] portrait_001.jpg
评分 (构,表,动): 8,9,7
  已保存: 构8.0 表9.0 动7.0 总8.1

[2/100] portrait_002.jpg
评分 (构,表,动): s    # 输入 's' 跳过
跳过
```

**图形界面模式**：
- 显示图片和三个输入框
- 输入 1-10 的分数
- 点击"保存并下一张"
- 支持快捷键 1-9 快速设置构图分数

### 3. 标注文件格式

标注文件 `annotations.json` 格式如下：

```json
{
  "photo_001.jpg": {
    "composition": 8.5,
    "expression": 9.0,
    "pose": 7.5,
    "overall": 8.3
  },
  "photo_002.jpg": {
    "composition": 6.0,
    "expression": 7.5,
    "pose": 8.0,
    "overall": 7.1
  }
}
```

**注意**：
- `overall` 是自动计算的，无需手动填写
- 总分 = 构图×0.4 + 表情×0.35 + 动作×0.25
- 文件名必须与图片文件一致

### 4. 启用精细标注

创建标注文件后，修改 `configs/config.yaml`：

```yaml
data:
  annotations_file: "./data/annotations.json"
```


## 标注评分指南

### 构图评分要点

**高分特征**：
- 主体位置符合三分法则或黄金分割
- 背景简洁不抢镜
- 画面有层次感和纵深感
- 线条引导视线到主体
- 裁剪得当，不截关节

**低分问题**：
- 主体偏离中心太远或太边缘
- 背景杂乱、有干扰元素
- 地平线歪斜
- 头顶/脚下留白过多或不足

### 表情评分要点

**高分特征**：
- 眼神有光、有故事感
- 笑容自然，不是假笑
- 情绪与场景匹配
- 面部肌肉放松

**低分问题**：
- 眼神呆滞或看别处
- 笑容僵硬或尴尬
- 闭眼、眨眼
- 表情与场景不搭

### 动作评分要点

**高分特征**：
- 姿态优雅，身体线条流畅
- 手势自然，不僵硬
- 动作与场景氛围协调
- 能展现被摄者的气质

**低分问题**：
- 身体僵硬、不自然
- 手不知道往哪放
- 姿态别扭或显得局促
- 动作与场景冲突

## 数据量建议

| 标注方式 | 最少数量 | 推荐数量 | 效果预期 |
|----------|----------|----------|----------|
| 简单分类 | 各 50 张 | 各 200 张 | 基础可用 |
| 多维度标注 | 100 张 | 500+ 张 | 专业效果 |

**数据多样性建议**：
- 不同光线条件（自然光/人工光/混合光）
- 不同场景（室内/室外/影棚）
- 不同风格（清新/情绪/时尚/复古）
- 不同被摄者（年龄/性别/气质）

---

## 支持的图片格式

- `.jpg` / `.jpeg`
- `.png`
- `.bmp`
- `.webp`

建议统一为 `.jpg` 格式，平衡质量与存储空间。
