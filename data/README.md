# Photo Pickout 项目

## 数据准备指南

### 目录结构

```
data/
├── good/          # 高质量照片（7-10分）
├── bad/           # 低质量照片（1-6分）
└── test/          # 待评分的测试照片（可选）
```

### 如何分类照片

#### good/ 文件夹（7-10分）
放入你认为**可以交付给客户**或**可以作为样片**的照片：
- ✅ 构图合理，主体突出
- ✅ 曝光准确，细节丰富
- ✅ 对焦清晰，主体锐利
- ✅ 表情自然，情绪到位
- ✅ 色彩协调，有层次感

#### bad/ 文件夹（1-6分）
放入你认为**有明显问题**的照片：
- ❌ 构图失衡，主体偏移
- ❌ 过曝或欠曝，细节丢失
- ❌ 对焦失败，画面模糊
- ❌ 表情僵硬或闭眼
- ❌ 色彩怪异或平淡无味

### 数据量建议

| 级别 | 最少数量 | 推荐数量 | 效果预期 |
|------|----------|----------|----------|
| 入门 | 各 50 张 | 各 100 张 | 基本可用 |
| 标准 | 各 100 张 | 各 300 张 | 较好效果 |
| 专业 | 各 300 张 | 各 500+ 张 | 稳定可靠 |

### 数据多样性

为了提高模型泛化能力，建议：

1. **场景多样化**
   - 室内 / 室外
   - 自然光 / 人工光
   - 不同背景环境

2. **人物多样化**
   - 不同年龄段
   - 不同性别
   - 不同表情/姿势

3. **风格多样化**
   - 明亮清新风
   - 暗调情绪风
   - 日系 / 欧美 / 复古

### 支持的图片格式

- `.jpg` / `.jpeg`
- `.png`
- `.bmp`
- `.webp`

### 注意事项

1. **保持诚实**：按照你真实的审美标准分类，不要为了凑数而模糊界限
2. **删除重复**：相似角度/表情的照片只保留一张
3. **原始文件**：尽量使用未修图的原始照片训练，模型会学习你的原生审美
4. **持续迭代**：随着模型使用，可以把误判的照片重新标注，持续优化

### 快速开始示例

```bash
# 1. 创建数据目录
mkdir -p data/good data/bad

# 2. 复制你的照片（示例）
cp ~/Photos/精选/*.jpg data/good/
cp ~/Photos/废片/*.jpg data/bad/

# 3. 检查数据量
ls data/good/ | wc -l  # 查看 good 数量
ls data/bad/ | wc -l   # 查看 bad 数量

# 4. 开始训练
python src/train.py --epochs 50
```
