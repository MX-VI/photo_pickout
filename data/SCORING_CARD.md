# 多维度标注评分参考卡

打印出来，标注时对照使用。

---

## 构图评分 (1-10)

| 分数 | 判断标准 |
|------|----------|
| 9-10 | 三分法/黄金分割完美，背景干净，层次丰富，引导线出色 |
| 7-8  | 构图合理，位置得当，无大问题 |
| 5-6  | 有小问题（稍偏、背景稍杂），但不致命 |
| 3-4  | 明显问题（倾斜、裁关节、主体偏移） |
| 1-2  | 严重构图失误（主体快出画、极度失衡） |

**关键检查点**：
- [ ] 主体位置合适
- [ ] 背景简洁
- [ ] 没有裁关节
- [ ] 地平线水平

---

## 表情评分 (1-10)

| 分数 | 判断标准 |
|------|----------|
| 9-10 | 眼神有故事，笑容自然，情绪到位，感染力强 |
| 7-8  | 表情自然，有情绪，但不够突出 |
| 5-6  | 表情平淡或略显僵硬 |
| 3-4  | 表情有问题（假笑、眼神呆滞） |
| 1-2  | 严重问题（闭眼、面部扭曲） |

**关键检查点**：
- [ ] 眼睛睁开且有神
- [ ] 笑容自然
- [ ] 情绪匹配场景
- [ ] 面部光线ok

---

## 动作评分 (1-10)

| 分数 | 判断标准 |
|------|----------|
| 9-10 | 姿态优雅，线条流畅，肢体语言到位，气质突出 |
| 7-8  | 姿态自然，动作协调 |
| 5-6  | 略显僵硬，但还能看 |
| 3-4  | 动作别扭，显得局促 |
| 1-2  | 姿态怪异，严重影响观感 |

**关键检查点**：
- [ ] 身体不僵硬
- [ ] 手有合适位置
- [ ] 姿态显气质
- [ ] 身材比例正常

---

## 快速打分口诀

**构图**：位置正不正？背景乱不乱？裁没裁关节？

**表情**：眼睁没睁？笑真不真？情绪对不对？

**动作**：僵不僵？手放哪？气质出来没？

---

## 总分计算公式

```
总分 = 构图 × 0.4 + 表情 × 0.35 + 动作 × 0.25
```

| 总分 | 等级 |
|------|------|
| 9-10 | 优秀 |
| 7-8  | 良好 |
| 5-6  | 一般 |
| 1-4  | 较差 |
