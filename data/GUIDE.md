# 照片好坏判断指南

给照片分类时，可以基于**三个核心维度**快速判断：构图、表情、动作。只要有两个维度表现不佳，就可以考虑放入 `bad/`。

---

## 快速判断流程

```
看照片 → 分别评估构图、表情、动作 → 综合判断是否可用
```

### 放入 good/ 的标准（满足任意即可）

| 情况 | 说明 |
|------|------|
| **三个维度都不错** | 构图舒服、表情自然、姿态协调 → 确定是 good |
| **两个维度很好，一个一般** | 比如构图 9 分、表情 8 分、动作 6 分 → good |
| **有一个特别突出** | 比如表情极其到位，其他过得去 → good |

### 放入 bad/ 的标准（满足任意即可）

| 情况 | 说明 |
|------|------|
| **有明显硬伤** | 闭眼、虚焦、严重过曝/欠曝 |
| **两个维度较差** | 构图歪+表情僵硬，或表情假+动作别扭 |
| **整体观感差** | 看一眼就觉得"这是废片" |

---

## 各维度具体判断标准

### 1. 构图 (Composition)

**Good 信号** ✅
- 主体位置自然（不偏心也不过于正中）
- 背景简洁，不抢镜
- 画面有层次感
- 裁剪得当（不截脖子、膝盖等关节）
- 地平线水平（除非特殊创意）

**Bad 信号** ❌
- 主体快出画了
- 背景杂乱、有干扰物（如路人、垃圾桶）
- 画面倾斜严重
- 头顶或脚下空间很不协调
- 裁到了关节（砍头、砍膝盖）

---

### 2. 表情 (Expression)

**Good 信号** ✅
- 眼神有焦点，有故事感
- 笑容自然，肌肉放松
- 情绪与场景匹配（开心的场景有开心的表情）
- 面部光线均匀，没有难看的阴影

**Bad 信号** ❌
- 闭眼、眨眼
- 眼神呆滞或看别处
- 假笑（皮笑肉不笑）
- 表情与场景冲突（严肃场景笑得开心）
- 面部扭曲（大笑变形过度）

---

### 3. 动作 (Pose)

**Good 信号** ✅
- 姿态优雅，身体线条流畅
- 手势自然，有目的性
- 整体看起来协调
- 能突出被摄者的气质

**Bad 信号** ❌
- 身体僵硬，像"站军姿"
- 手不知道往哪放（比如不知所措地垂着）
- 姿态别扭，显得局促
- 动作与场景气质不符（如优雅场景做搞怪动作）
- 站姿导致身材比例变形（如显得腿短）

## 实战示例

### Example 1 - 明显是 Good
```
照片：户外逆光人像
- 构图：主体在黄金分割点，背景虚化干净 ✓
- 表情：眼神温柔，嘴角微微上扬，自然 ✓
- 动作：侧身回眸，姿态优雅 ✓

结论：三个维度都不错 → good/
```

### Example 2 - 明显是 Bad
```
照片：室内人像
- 构图：头顶留空太少，显得压抑 ✗
- 表情：闭眼 ✗
- 动作：手插口袋但肩膀耸起，僵硬 ✗

结论：两个维度有问题且有硬伤 → bad/
```

### Example 3 - 边界情况
```
照片：街拍人像
- 构图：背景有点杂，但主体突出 ⚠️
- 表情：非常自然，笑容感染力强 ✓
- 动作：走路姿态自然 ✓

结论：表情特别出色，整体可用 → good/
```

## 分类小技巧

### 批量处理时的快速方法

1. **先筛一遍废片**
   - 闭眼、虚焦、严重过曝/欠曝的直接丢进 bad/
   - 这一步可以用肉眼快速过一遍

2. **再分剩下的**
   - 剩下的照片仔细看构图、表情、动作
   - 感觉"可以交付给客户"的放 good/
   - 感觉"需要重拍或勉强可用"的放 bad/

3. **不确定的暂时跳过**
   - 实在拿不准的先不放
   - 等两边数量差不多了再回来看

### 数量平衡

- 尽量让 good/ 和 bad/ 数量接近（比如 1:1 或 4:3）
- 如果 good/ 太多，可以提高标准
- 如果 bad/ 太多，可以降低标准或拍更多好照片

## 常见误区

❌ **误区 1：只看技术参数**
- "这张照片曝光准确、对焦清晰，所以是 good"
- 错！表情和动作不好，技术再完美也是废片

❌ **误区 2：只看模特颜值**
- "模特好看，所以是 good"
- 错！表情僵硬、姿态别扭，好看也救不了

❌ **误区 3：过度纠结**
- "这张照片构图 7 分、表情 6 分、动作 7 分，算不算 good？"
- 别纠结！整体感觉可用就放 good，犹豫的就先跳过

✅ **正确心态**：
- good/ 放"你愿意展示给别人的作品"
- bad/ 放"你不愿意让别人看到的照片"

---

## 进阶：为精细标注做准备

如果你打算后续做精细标注，可以在分类时简单记一下每个维度的表现：

```
photo_001.jpg - 构8 表9 动7 (good)
photo_002.jpg - 构6 表5 动6 (bad)
```

这样后续标注时效率会高很多。
